## AC

1. Pipeline tab uses a horizontal layered layout, not a freeform physics graph.
2. Nodes = tasks; agent/role is secondary metadata.
3. Edge/lane kinds are distinguishable without color alone.
4. States: queued, running, complete, approval, blocked, failed, skipped — each with icon + shape + label.
5. Selecting a node drives the same inspector as Overview (C3).
6. Reduced-motion safe; only running state receives subtle activity motion.
7. Narrow width fallback: show Overview list + full-height task detail; do not shrink the pipeline into a mini-map.
8. Verify against `thewhatmatters/sagan` @ `ab2cb8d`.
