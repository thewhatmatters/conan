## Ledger write semantics

- Append atomically and leave the ledger uncommitted. No auto-commit, staging, or `git add`.
- Use a single `fs.appendFileSync` call with the entire line (JSON + trailing `\n`).
- A2 parser must tolerate an unparseable final line (partial write / crash) by skipping it.
- Compare-and-append: immediately before writing, re-resolve `(ticket, gate)` from the ledger tail. If the last event is no longer `decision.needed`, append nothing and surface the resolved audit view.
- Newline guard: if the ledger file does not end in `0x0a`, prepend `\n` to the appended line.
- Success state: toast "Decision recorded in `.sagan/ledger/events.jsonl`. Commit it with the related work." Inspector audit line: "Recorded by <actor> · <timestamp> · `.sagan/ledger/events.jsonl`" with optional **View file** action.
