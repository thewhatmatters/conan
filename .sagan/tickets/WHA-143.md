## AC

1. Selecting a run/ticket opens an in-surface inspector (no chat remount).
2. Inspector shows: objective, lane/role, provider, containment, attempt/ticket id, timestamps, status, output/artifacts, read-only transcript.
3. "Open owning thread/session" only appears when a real thread/session target exists; otherwise hidden.
4. No live composer inside the inspector.
5. Verify against `thewhatmatters/sagan` @ `ab2cb8d` with a non-empty transcript.

## Frontend

- Added a selected-ticket inspector inside the existing Sagan surface; selecting
  a row swaps only the surface body, leaving the chat route and `V2ChatView`
  selection untouched.
- Inspector renders objective, lane/role/agent, provider, containment, ticket
  and attempt IDs, status, timestamps, output/artifacts, and the complete
  read-only ledger-event transcript. It contains no composer.
- Detail metadata normalizes `ts` and `timestamp`, reads a ticket heading as the
  objective fallback, resolves lane provider/containment from `sagan.yaml`, and
  exposes thread/session/nostr targets only when the ledger records one.
- Escape and the Overview button close the inspector; focus enters on open and
  returns to the triggering run row on close. Rows and the close control retain
  visible focus rings.
