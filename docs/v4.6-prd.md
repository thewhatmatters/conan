# Conan v4.6 — PRD

Compiles `docs/v4.6-backlog.md` (9 themed items) into a build spec for
`decompose-prd` → `prd.json` → `run-tasks.sh`. Each story below carries
acceptance criteria; the backlog holds the full rationale, root-cause diagnoses,
and file pointers — this PRD references it rather than repeating it.

**Default decisions baked in (were open questions in the backlog):**
- **MCP auth (F1):** drive a **throwaway pty** (not the correlated session); the
  `/mcp` TUI recipe is a **spike** (F1-S1) gating the rest.
- **HUD toolbar (F2):** extract a shared `<HudTabHeader>`; retrofit Skills/MCP
  onto it for one canonical spec.
- **Settings (F4):** keep **both** Status + Config tabs; Status becomes editable;
  framing = Status (set values, by source) vs Config (full catalog, by file).
- **Responsive (F7):** bottom-dock replaces auto-hide; below a **window-height
  floor**, keep the menu toggle as the escape hatch (no unusable sliver).
- **Appearance fonts (F8):** **curated-list + canvas-detection** (works in
  WKWebView); full gateway enumeration deferred. Include a font-size control.
- **Themes (F9):** a theme carries `type: light|dark`; selecting sets tokens +
  `.dark`; **"auto"** maps to a default light/dark pair. ANSI-16 palette + in-app
  theme editor are **out of scope**.

## Goal
Polish + extend the Conan HUD/observation surface and make it personalizable:
fix two real bugs (Pulse axis, redundant Timeline ×), unify HUD chrome, surface
the full `/usage` stats, make MCP servers fixable in-app, make Settings editable
and consistent, add a responsive bottom-dock layout, and open up appearance
(mono font + multiple themes from a config file).

## Out of scope
- The `/stats` TUI screen (separate from `/usage`).
- Terminal ANSI-16 color palette in themes (themes reskin chrome + term bg/fg).
- In-app theme editor/creator (edit the JSON file by hand).
- Full system-wide font enumeration (curated-detect ships; enumeration deferred).
- Live `fs.watch` reload of the themes file (nice-to-have follow-up).

## F1 — MCP tab: one-click authenticate / reconnect
Backlog §"MCP tab — one-click authenticate / reconnect". `claude mcp` has **no
auth subcommand** (verified) → must drive the `/mcp` TUI via a throwaway pty.

- **F1-S1 (SPIKE): Capture the `/mcp` TUI recipe.** Drive `/mcp` in a pty, record
  the frame sequence; document (a) server ordering vs `claude mcp list`, (b) the
  keypresses to select a server + trigger Authenticate, (c) the post-auth/pending
  frame. *AC:* a written, deterministic navigation recipe committed to
  `docs/` (or a verdict it's too brittle + an alternative). Typecheck clean.
- **F1-S2: MCP-auth pty driver (backend).** In `src/mcp/`, reuse the
  `src/usage/probe.ts` throwaway-pty lifecycle: spawn `claude`, inject `/mcp`,
  run the F1-S1 navigation for a named server, fire Authenticate, kill the pty;
  never throws; cleans up on timeout. *AC:* unit-tested against a captured frame;
  `npm test` + typecheck clean.
- **F1-S3: Completion polling (backend).** After firing auth, poll
  `getMcpServers(true)` until the target flips to `connected` or a timeout;
  expose `pending|connected|timeout`. *AC:* tested; typecheck clean.
- **F1-S4: Routes.** `POST /api/claude/mcp/:name/authenticate` and
  `.../reconnect` (reconnect = forced re-health-check, escalate to auth only when
  auth-shaped), token-gated like the probe. *AC:* token-gated (401 without
  token); typecheck clean.
- **F1-S5: Inline row actions (UI).** In `McpWidget.tsx`: **Authenticate** on
  `needs-authentication` rows, **Reconnect** on `failed` rows; per-row in-flight
  state; success repaints via `useMcp` refresh; honest copy ("opens your
  browser" / "only re-checks health"). *AC:* verified with `automate-browser`
  (light+dark): right action per status, in-flight state, no action on
  `connected`; UI build clean. Native note: real OAuth handoff verified in the
  built app.

## F7 — Responsive: bottom-dock the HUD at narrow widths
Backlog §"Responsive — dock the HUD to the bottom". Replace the narrow-width
auto-hide with a vertical stack (terminal ~67% / HUD ~33%, resizable).

- **F7-S1: HUD dock orientation.** Add `dock: "right" | "bottom"` to `Hud`;
  abstract the resize to drive width+left-handle+`border-l`+`conan-hud-w`
  (`right`) vs height+top-handle+`border-t`+`conan-hud-h` (`bottom`), clamped to
  per-axis min/max; default 33% height for bottom. *AC:* both docks resize +
  persist independently; typecheck + UI build clean.
- **F7-S2: Shell reflow.** In `App.tsx`, flip the root to `flex-col` below the
  breakpoint (rename it — no longer a *hide* breakpoint); render `TerminalPane`
  (top, `flex-1`) + `Hud dock="bottom"`; `dock="right"` when wide; drop the
  `|| hudCrampedHide` force-hide so `hidden` is purely `!hudOpen`. *AC:*
  `automate-browser` at wide / narrow / narrow+timeline-open: HUD bottom-docks at
  narrow instead of hiding; the horizontal divider resizes it; menu toggle still
  hides it; UI build clean.
- **F7-S3: Min-size + short-window guard.** Add `useWindowHeight`; enforce
  terminal + HUD min heights; below a window-height floor keep the menu toggle as
  the escape hatch (clamp, don't render an unusable sliver). *AC:*
  `automate-browser` at narrow+short: no unusable sliver; sizes restore per
  orientation on wide↔narrow; typecheck + UI build clean.

## F9 — Appearance: multiple themes from a config file
Backlog §"Appearance — multiple themes from a config file". Supersedes F8's
"themes later" note. A theme = a value-set for the ~20 `:root` tokens.

- **F9-S1: Theme model + built-ins.** Define the token-key contract + `Theme`
  type; bundle built-ins (Light, Dark, +a few) in the UI; a `useThemes` hook (or
  extend `useTheme`) merging built-ins + user themes, exposing active theme +
  setter persisted by `id`. *Depends on F8-S1.* *AC:* typecheck + UI build clean.
- **F9-S2: Apply path.** Replace the `.dark`-only `apply()` with: set the theme's
  tokens on `documentElement` + toggle `.dark` per `type`; "auto" maps to a
  light/dark default pair; re-read the terminal theme on all mounted terms;
  partial themes merge over the built-in default. *AC:* `automate-browser`:
  switching reskins app + terminal live + persists; partial theme falls back;
  "auto" follows OS; UI build clean.
- **F9-S3: Config-file route.** `GET /api/claude/themes` (token-gated) reading
  `~/.conan/themes.json` (CONAN_DATA_DIR-aware), **validating** token keys +
  color values, returning user themes to merge; skip invalid entries (logged).
  *AC:* token-gated; `npm test` (validation rejects bad keys/colors + raw CSS);
  typecheck clean.
- **F9-S4: Appearance-tab selector + menu.** Theme picker (list + palette
  swatches) in the Appearance tab; selecting applies live + persists; grouped by
  light/dark; update the View ▸ Theme submenu (`appMenu.ts`) to match. *AC:*
  `automate-browser` + native: picker switches themes; a `themes.json` user theme
  appears + applies; menu stays in sync; UI build clean.
