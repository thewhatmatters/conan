# Conan v4.2 — Tremor charting + aggressive Tauri-only cleanup

Backlog to research → PRD → decompose → loop. Same flow as prior versions.
Charting research (the open risk): `docs/v4.2-research.md`.

## Two themes
1. **Adopt Tremor (https://www.tremor.so/) as the charting library going forward.**
   Replace the hand-rolled SVG charts with Tremor and make it the standard for any
   future chart. Migrate the two charts in the current cut:
   - **Pulse** — `ui/src/components/PulseChart.tsx`: a stacked **area** chart of
     activity categories over time (15m/1h/6h/24h ranges), categories mapped to
     `--color-chart-1..5`.
   - **Context** — the `Ring` gauge in `ui/src/components/Widgets.tsx`: a context-
     window **% donut/progress** gauge.
   - **Plus: capture the *real* `/context` breakdown.** The Context widget should
     show the exact information from Claude Code's `/context` command — model header,
     total/window %, and per-category tokens+% (System prompt, System tools, MCP
     tools, Memory files, Skills, Messages, **Free space**) — not just the on-disk
     estimate. Because `/context` is session-specific, this is captured from the
     correlated **live pty** (passively when the frame appears, plus an on-demand
     Refresh that injects `/context`), parsed like the `/usage` probe; the disk
     estimate stays as the fallback. (prd.json US-009.)
   - **Plus: capture the full `/usage` screen.** The Usage widget should show the
     exact `/usage` information — the **Session block** (total cost, API/wall
     duration, code changes, per-model input/output/cache + cost) and **all three**
     rate-limit windows (Current session, Current week all-models, Current week
     Sonnet-only). The windows are account-global (the existing throwaway-probe in
     `src/usage/probe.ts` gets them — extend it from 2→3 windows); the Session block
     is session-specific, so it's captured from the correlated **live pty** (passive +
     Refresh), same as `/context`. Precedence: live frame → probe windows →
     token-trend baseline. (prd.json US-010.)
   - **Plus: native OS notifications for Claude's prompts.** Surface to the macOS
     Notification Center when a Claude session needs the user (permission prompt /
     waiting for input) so it isn't missed while Conan is in the background. Trigger =
     the already-installed **`Notification` hook** (flows `hook → /api/claude/events →
     /ws {type:'event'}`, payload carries `message`); fire via Tauri's
     `@tauri-apps/plugin-notification`, suppressed when the window is focused +
     de-duped, click brings Conan forward to acknowledge. Falls back to the in-app
     Toaster in the browser. Stretch: interactive Allow/Deny routing to the pty via
     the v4 keystroke injection. (prd.json US-011.)
   - **Decided (research: `docs/v4.2-research.md`): use Tremor Raw, NOT `@tremor/react`.**
     The legacy `@tremor/react` npm package needs a Tailwind-v3 `tailwind.config.js`
     (`content` glob into `node_modules/@tremor/**` + a color safelist) and does not
     render on Tailwind v4 — do not install it. **Tremor Raw** is the current,
     shadcn-style **copy-in** model and is **Tailwind v4-native** (no config, no
     safelist). You vendor the component source (`AreaChart.tsx`, `ProgressCircle.tsx`)
     + `lib/chartUtils.ts` into the repo; the only new deps are **`recharts`** +
     **`tailwind-variants`**. Theme by rewriting `chartUtils.ts` color names to
     `…-[var(--color-chart-N)]`, so charts honor our existing tokens + `.dark` for free.
     **Cost:** Tremor charts are Recharts wrappers → ~100 KB+ gzipped (today's charts
     are zero-dep). Acceptable for a local-sidecar desktop app; this intentionally
     reverses the old "zero charting deps, hand-rolled SVG" decision. The
     `ContextBreakdownBar` stays hand-rolled (Tremor adds nothing there).

2. **Aggressive Tauri-only cleanup** (decided 2026-05-27): delete everything not
   related to the Tauri desktop app, including trimming the gateway to only what the
   terminal-wrapper needs and dropping the browser/web-served production path.

## Cleanup — keep vs delete

### KEEP (the Tauri app + what feeds it)
- `src-tauri/*` (the desktop app), the sidecar build (`scripts/build-sidecar.mjs`,
  `runtime/`, `test-sidecar`), `docs/tauri-desktop.md`.
- UI: the terminal-primary shell + HUD — `App.tsx`, `TerminalPane.tsx`, `Terminal.tsx`,
  `Hud.tsx`, `Widgets.tsx` (Context + Usage cells), `PulseChart.tsx` (→ Tremor),
  `Toaster.tsx`, `lib/{gateway,appMenu}.ts`, `components/ui/*` (shadcn), the surviving
  hooks: `useTheme, useTasks (app WS), useSessions, useUsage, useTerminals, usePulse,
  useWidgets`.
- Gateway: only the routes the UI calls + their support —
  `GET /api/health`, `GET /api/config`, `GET /api/tasks` (feeds Toaster + the `/ws`
  connection), `GET /api/terminals`, `GET /api/claude/sessions` (list),
  `GET /api/claude/sessions/:id/widgets` (Context), `GET /api/claude/usage` (+`?probe=1`),
  `GET /api/claude/pulse`, `POST /api/claude/events` (hook ingestion), and the two
  WebSockets `/ws` + `/ws/terminal`. Plus their backing modules: DB, auth/Origin,
  session tracking + liveness reaper + pty↔session correlation, usage probe, pulse,
  terminal/pty, the context-breakdown source for the widgets route, and the hook
  scripts that populate the DB.
- Build/dev infra: `run-tasks.sh`, `prd.json`, `progress.txt`, `CLAUDE.md`, `README.md`,
  `package.json`, and the **Vite dev server (:5173)** — kept for development + loop
  UI-verification (it's the dev server, not the web-served production path).

### DELETE (not part of the Tauri app)
- **Unused gateway routes + their src modules + tests:** `/api/claude/{agents,
  background-agents,changelog,checkpoints,doctor,hooks-coverage,mcp,permissions,plugins,
  project-metrics,prompt-history,skills,skills/list,stats,ultrareview(+/stop),
  hooks/install-global}`; the **session-drive** surface `POST /api/claude/sessions`,
  `:id/{prompt,resume,stop,permission}` and `GET :id/{events,subagents,transcript}`;
  `GET/POST /api/settings` + `/api/claude/settings`; `/api/cwd`, `/api/cwd/git`,
  `/api/fs/dirs`. Delete each route's `src/**` module + its `scripts/test-*.mjs`.
- **Web-served / remote bits (Tauri-only):** the gateway's static SPA serving of
  `ui/dist` for browsers, `src/gateway/tls.ts` + `docs/remote-access.md`, the
  remote-control/Chrome + worktree session docs, pm2 (`ecosystem.config.cjs`,
  `npm run ops:*`, `docs/ops.md`).
- **Legacy planning + history:** the multi-version PRD `prd-claude-code-dashboard.md`
  and `research-claude-code-always-on-dashboard.md`; `docs/v2-backlog.md`,
  `docs/v3-backlog.md`, `docs/v4-backlog.md`, `docs/v4-research.md`,
  `docs/v4.1-backlog.md`/`research`(fold the essentials into a single current spec);
  `archive/`. (Keep a single concise current spec — e.g. a trimmed PRD or the README —
  rather than the full v1→v4 history.)
- Any UI hook/component left orphaned after the route deletions.

## Risks / sequencing notes
- **Widgets route interdependency:** `GET /api/claude/sessions/:id/widgets` (Context
  breakdown) reconstructs category sizes from on-disk MCP/skills/memory — so deleting
  the MCP/skills modules wholesale can break it. Trim carefully; the widgets route must
  still return after each deletion. Build is the gate.
- **Sidecar must be rebuilt** (`npm run build:sidecar`) after gateway trimming so the
  packaged binary reflects the smaller surface; re-run `test:sidecar` (DB + pty).
- **Dev-verification shifts to Vite :5173** (gateway no longer serves the SPA to a
  browser). Loop stories' "verify in browser" target `http://localhost:5173` with
  `cd ui && npm run dev` running.
- **Sequence:** do the cleanup (subtraction) first so the surface is small, then adopt
  Tremor (addition) on the trimmed UI — keeping the build green at every story.

## What this discards
The last of the dashboard-era surface: all observe/drive routes the terminal-wrapper
doesn't use, the browser/remote deployment path, and the v1→v4 planning history. Conan
becomes strictly the Tauri terminal-wrapper + the minimal gateway that feeds its
Terminal + Context/Usage/Pulse.
